# InfoVia — versão de teste (BETA)

Avisos de trânsito entre condutores de **Pemba** e **Nampula**: filas, buracos, controlos rodoviários e acidentes, com som e voz, para não precisar de olhar para o telemóvel.

> Esta é uma **versão de teste**. Podem aparecer erros. A sua opinião ajuda a melhorar a app.

## Descarregar (Android, cerca de 5 MB)

| Cidade | Link |
|---|---|
| **Pemba** | [InfoVia-Pemba.apk](https://github.com/Mahota3/infovia-beta/releases/latest/download/InfoVia-Pemba.apk) |
| **Nampula** | [InfoVia-Nampula.apk](https://github.com/Mahota3/infovia-beta/releases/latest/download/InfoVia-Nampula.apk) |

Os links dão sempre a versão mais recente. Versões anteriores: [Releases](https://github.com/Mahota3/infovia-beta/releases).

## Instalar

1. Toque no link da sua cidade e descarregue o ficheiro.
2. Abra o ficheiro descarregado. Se o Android pedir, permita **"instalar de fontes desconhecidas"** para o navegador ou para a app de ficheiros.
3. Se aparecer um aviso do Play Protect, toque em **"Instalar mesmo assim"** (a app ainda não está na Play Store).
4. Abra a InfoVia e permita a localização.

Para atualizar, descarregue o link de novo e instale por cima: os seus dados ficam.

## Como usar

- **Segure** o botão laranja meio segundo e, sem levantar o dedo, **deslize** para o tipo: ▲ Trânsito Lento · ▶ Perigo na Via · ◀ Controlo Rodoviário · ▼ Acidente / Avaria. Solte para enviar.
- Tem **6 segundos para "Desfazer"**.
- Soltar sem deslizar **marca o local** para classificar depois.
- Ao chegar perto de um alerta de outro condutor, ouve um som e um aviso de voz.
- No topo, **ⓘ** explica tudo passo a passo.

**Segurança:** não manuseie o telemóvel com o carro em andamento. Use um suporte e ouça os avisos em alta-voz.
